# 开发计划

功能清单和勾选记录在 claude.ai 的清单页上，键盘交互原型在原型页上。这里记录工程上的阶段。

## 阶段 0 · 技术验证 ✅

- librime + 雾凇拼音编进 APK（arm64），JNI 桥自己写，编译方案参考 Trime。
- 主机上验证过：部署成功，整句、emoji、繁体、Lua（日期、计算器）、中英混输都正常。

## 阶段 1 · 中文能天天用（本次提交）

已完成：布局引擎（YAML）、中文 26 键、俄英键盘、四向滑动、长按拖动选择、空格切语言与拖光标、删除键手势、符号面板、数学键盘、光标面板、剪贴板、按输入框类型切键盘、按应用记住语言、设置界面、按键与弹层动画。

待真机验证后打磨：

- 外观细节（字体、阴影、间距），深色主题实机效果。
- 首次部署词库的耗时；如果太慢，改为编译时预先部署、把二进制词典打进 APK。
- emoji 面板（现在先用颜文字顶着）。

## 阶段 2 · 俄语和云能力

俄英单词补全、云端语音（中文讯飞/阿里云/腾讯云，俄语 Whisper 系）和 AI 整理、翻译栏、中文云候选、词库订阅、剪贴板识别。

## 阶段 3 · 打磨

俄英纠错、One UI 外观细抠、撤销、同步与备份、输入统计、俄语重音、手机上可视化改键。
